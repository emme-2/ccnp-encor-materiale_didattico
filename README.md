## Ambiente Lab

| Piattaforma | Supporto |
|-------------|---------|
| GNS3 + IOU L2/L3 | ✅ Nativo |
| ContainerLab + vrnetlab/IOU | ✅ Compatibile |
| EVE-NG | ✅ Compatibile |

Le configurazioni iniziali sono in sintassi IOS, compatibili con tutte e tre le piattaforme.
Server TFTP di riferimento: `192.168.122.1` — path: `ENCOR/MOD-xx/device-cfg`

## Come Usare il Materiale

1. Scarica i PDF dalla sezione **Releases**
2. Ogni modulo è autonomo — inizia da quello che ti serve
3. Segui la sezione **LAB SETUP** per caricare le configurazioni iniziali:
   ```
   Router# copy tftp: running-config
   Address or name of remote host? 192.168.122.1
   Source filename? ENCOR/MOD-xx/device-cfg
   ```
4. Leggi la sezione **TEORIA** prima di iniziare i task
5. Usa i comandi di **VERIFICA** dopo ogni task per confermare il risultato
6. In caso di problemi consulta la **TROUBLESHOOTING GUIDE**

## Script

### `generate_slides.py` — Generazione slide PPTX

```bash
python generate_slides.py          # tutti i moduli
python generate_slides.py MOD-01   # solo un modulo
```

Output: `MOD-XX/MOD-XX_slide.pptx`

### `export_pdf.py` — Esportazione PDF

Converte `workbook.md`, `soluzione.md` e `note_docente.md` in PDF A4.
I diagrammi Mermaid vengono renderizzati automaticamente via Chrome headless.

**Prerequisiti:** `pip install pymdown-extensions` · Google Chrome installato

```bash
python export_pdf.py               # tutti i file
python export_pdf.py MOD-01        # solo un modulo
python export_pdf.py --force       # rigenera anche se il PDF esiste già
python export_pdf.py --css-only    # rigenera solo il foglio di stile
```

Output: `EXPORT/PDF/` (esclusa dal repo — rigenerare localmente)
